# Invoice Ninja API Documentation

This is the API documentation for the Invoice Ninja API.

## Getting Started

To get started, you need to have an Invoice Ninja account and API credentials.

## API Reference

The API reference is available [here](https://api-docs.invoicing.co/api-docs.yaml).

## Building the documentation

To build the documentation, you need to run the following command:

```bash
redocly build-docs api-docs.yaml --template template.hbs --output ./docs/index.html
```
